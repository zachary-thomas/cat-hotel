# Creative Social Hotel Implementation Plan

**Goal:** Implement the user-approved creative hotel, four distinct maps, editable social venues, expandable land, cottages, paths, unfinished rooms, and isolated playable preview.

**Architecture:** New `scripts/creative/` subsystem and `scenes/creative_hotel.tscn`; preserve the legacy scene and user work. Reuse original cats, shaders, fonts, UI colors, audio, and progression content. All edits are transactional through the new model, all geometry shares one lot coordinate system. No new runtime dependencies.

**Spec:** User-approved complete plan in the September 15 conversation. Fresh preview only, no existing-save conversion. Keep destination unlocks/entitlements, earned currency, 20-step undo, single-story rectangular construction, dynamic room counts and readiness.

## Shared interface contract

Coordinates: lot cells are 1.1 world units, `(x,y)` maps to world `(x*1.1,0.18,y*1.1)`. Objects snap to half cells, rooms and paths to whole cells. All persisted data is JSON-safe dictionaries/arrays/numbers/strings. World coordinates of objects are saved directly. Room membership is `room` string, empty for outdoor. Rotations are 0..3 quarter turns. Stored room w/h are unrotated; geometry swaps them on odd rotation. Objects have unrotated footprint sizes from content.

`creative_content.gd` static `item(id:String)->Dictionary`, `items(category:String="")->Array`, `templates()->Array`, `template(id:String)->Dictionary`. Item fields: id,name,category (Furniture/Outdoors), cost, size:[w,h], color:hex, shape:String, tags:Array[String], surfaces:Array[String] (indoor/outdoor), role:String (bed/seat/reception/bar/play/sun/warm/decoration/amenity/fence/gate), capacity:int, service:int (-1/0/1/2/3). Template fields id,name,description,kind(shared/terrace),w,h,objects:[{item,x,y,rotation}], tags. Template coordinates local; all bits individually editable. Include existing furniture and amenities with known prices, new outdoor prices and social anchors. Content agent owns this file and `creative_maps.gd`.

`creative_maps.gd` static `definition(index:int)->Dictionary`. Fields id,name,theme,ground:hex,accent:hex,arrival:[x,y],base:[x,y,w,h],plots:[{id,name,cost,rect:[x,y,w,h]}],rooms:[{id,kind,name,x,y,w,h,rotation,paid}],objects:[{id,item,room,x,y,rotation,paid}],paths:[{x,y,style,paid}],scenery:[{kind,x,y,size,color}]. Starter geometry uses same coordinate rules, two regular rooms + shared lobby + themed social area and connected paths. Parcel IDs west/east/north prices750/750/1000; no fixed wing mechanics. Rooms have complete rect shells; shared roofs optional via kind terrace. Objects have half-cell dimensions; must fit their room and avoid other footprints. Leave clearance at east-facing midpoint doors for rotation0 (south1,west2,north3). Arrangement IDs lobby,milkshake,lounge,play,sunroom,terrace.

`creative_model.gd` instance has `state`, `social`, `revision`. State keys version,coins,current_hotel,hotels,storage,cats,settings,next_id,time,last_seen,pending_coins,entitlements. Hotel fields owned,plots,rooms,objects,paths(dictionary keyed `x,y` with {style,paid}),level,upgrades:[four ints],staff:[three ints],visits,happy,cleaned. Methods: `new_game(now:int=0)`, `hotel(index:int=-1)->Dictionary`, `map_definition(index:int=-1)`, `quote(action:String,payload:Dictionary)->Dictionary`, `commit(action,payload,save:Callable=Callable())->Dictionary`, `undo(save)`, `redo(save)`, `serialize`, `restore`, `reconcile(now)`, `advance(seconds)`, `rate(index=-1)`, `room_status(id,index=-1)->Dictionary`, `venues(index=-1)->Array`, `route(from:Vector2,to:Vector2,constructed:bool=true,index:int=-1)->Array`, `finish_visit(cat:int,tags:Array)`, `travel(index,save)`, `care(cat,action)`. Status {ready,status,message}. Venue {id,item,name,x,y,tags,role,service,open,status,capacity,slots:[{key,x,y,action}]}. Route points in lot units. Quotes {ok,message,cost,displaced:Array}; negative cost is refund. Public commands: buy_plot{id}; place_room{kind,x,y,w,h,rotation,name?}; move_room{id,x,y,rotation}; resize_room{id,w,h}; remove_room{id}; copy_room{id,x,y,rotation}; place_template{template,x,y,rotation}; place_object{item,x,y,rotation}; move_object{id,x,y,rotation}; store_object{id}; retrieve_object{id,x,y,rotation}; paint_path{cells:[[x,y]],style}; erase_path{cells}; upgrade{service}; train{staff}. Room templates/copies atomically place all pieces. Quotes never mutate. Save callable accepts model, returns bool. Failed commit restores state and history; previews kept by UI. Undo rebates only operation delta, leaves elapsed income/social data intact. New paths styles earth/gravel/brick.

`lot_geometry.gd` static geometry / occupancy helpers (root-owned) plus model routing. `room_rect(room)->Rect2`, `object_rect(object)->Rect2`, `door(room)->Vector2`, `point_owned(point,map,hotel)->bool`. Geometry renders and validates all surfaces.

`social_simulation.gd` instance `model`, `agents:Dictionary`, `reservations:Dictionary`, `advance(seconds)`, `reset()`. Agent records `cat:int,position:Vector2,action:String,venue:String,phase:String`; renderer reads these. Simulation owns routes, timing and slot reservations and calls model.finish_visit for completed visits. Activities use actual venues, rooms, unique named cats, preferences and recent history; reseat/replan on model revision. No visual-triggered rewards. World agent owns social and world/objects rendering.

`creative_world.gd` Node3D: `setup(model)`, `sync()`, `set_world_rect(rect:Rect2)`, `focus_hotel()`, `focus_lot()`, `focus_bounds(bounds:Rect2)`, `pan(relative:Vector2)`, `zoom(factor:float)`, `world_point(screen:Vector2)->Vector2`, `set_preview(action:String,payload:Dictionary,valid:bool)`, `clear_preview()`, `set_outside(bool)`. Model state/definitions are source of truth; render on revision and animate actors from model.social.agents every frame. Camera uses actual unobstructed world rect. No fixed legacy hotel geometry. All four complete maps, coherent exterior/cutaways, object shapes matching thumbnails, preview footprints. Root can extend API by agreement.

`creative_ui.gd` Control: var app; `refresh()`, `world_rect:Rect2`, `build_mode:bool`, `preview_action:String`, `preview_payload:Dictionary`; uses app.model,app.world,app.perform(action,payload)->Dictionary,app.save()->bool,app.travel(index)->Dictionary,app.care(cat,action)->Dictionary. UI handles mouse/touch and camera input inside world_rect. Six Build categories, context selection/actions, press/drag room move and path strokes, compact/expanded trays, Undo/Redo, real thumbnails, readiness, map/cats/life/settings screens. Root `creative_app.gd` app supplies model/world/ui and journal save boundary, audio and scene. UI agent owns UI and item thumbnail helper only.
