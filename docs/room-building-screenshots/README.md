# Room building rework

Captured from the actual Godot game using the isolated rendered building test on September 9, 2026. Test hotels use earned-coin fixtures and restored wings to demonstrate the features; they do not modify normal player saves.

- `suite-furnishings.png`: selected suite, sitting area, mint outline and illustrated furniture catalogue.
- `suite-placement.png`: translucent suite placement before purchase.
- `hotel-overview.png`: seven individually placed rooms and suites with public services and gardens.
- `portrait-object-preview.png`: 360 × 800 layout with visible room, object preview, purchase and cancel controls.

Run `tests/test_building.gd` with a rendered Godot process at 1280 × 800 or 360 × 800 to recreate the captures in `tmp/`.
