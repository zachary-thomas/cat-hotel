# Original Purrington audio

All audio in this directory is synthesized from original code in tools/generate_audio.py. There are no external samples or third-party compositions. Run that script with Python and NumPy to reproduce the WAV assets.

The soundtrack uses plucked tones, soft chords, bass and brushed rhythm. Cartoon cat voices are synthesized from changing pitch and vowel-like harmonic filters. Assets are 22.05 kHz PCM; music is stereo and sound effects are mono. The runtime supplies looping, crossfading, relative volumes, and playback cooldowns.
